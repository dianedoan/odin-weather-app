# Weather App
This [webpage](https://dianedoan.github.io/odin-weather-app/) is a basic Weather application containing the following features:
- Display weather information and related weather icons for a specific location
- Search bar to lookup weather information for a specific location
- Toggle to display the data in Fahrenheit or Celsius
- Background and text color changes based on if it is night or day for the location

This weather app uses the [Visual Crossing](https://www.visualcrossing.com/weather-api) weather API to gather weather data.

## Description
This project demonstrates the skills learnt from the JavaScript Course in The Odin Project up until the [Async and Await](https://www.theodinproject.com/lessons/node-path-javascript-async-and-await) topic.
